# Digisol Network & Cloud Engineering Internship

## Overview
A practical internship focused on network engineering,
Linux administration, cloud infrastructure, automation,
deployment, monitoring, and security.

## Environment
- Operating system: Ubuntu 24.04 LTS on WSL 2
- Version control: Git and GitHub
- Networking tools: curl, dig, ip, ping, traceroute, tcpdump

## Project Structure
- linux/ — Linux administration practice
- networking/ — Networking labs and troubleshooting
- nginx/ — Web server and reverse proxy projects
- aws/ — Cloud infrastructure labs
- terraform/ — Infrastructure as Code
- automation/ — Automation scripts
- documentation/ — Notes and project documentation
